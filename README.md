# Quran-Reader 📖

A bilingual console-based Quran reader built with Python. It allows users to explore the Holy Quran in Arabic and read English translations directly from the terminal.

✨ Features

📚 Browse all 114 Surahs of the Holy Quran.

📖 Read Surahs and individual Ayahs in Arabic and English.

🔎 Search Surahs by name or number.

🎯 Navigate directly to a specific Ayah.

⭐ Save and manage favorite Ayahs.

💾 Automatically save your reading progress.

🌐 Switch between English and Arabic interfaces.

📁 Cache Quran data locally for easier access.

🛠️ Technologies

Python 3

JSON for local data storage

urllib for API requests

AlQuran Cloud API for Quran text and translations

🚀 Getting Started

Clone this repository.

Make sure Python 3.10 or newer is installed.

Open a terminal in the project directory.

Run the application:

python quran_reader.py

An internet connection is required to download Quran data when it is not available locally.

📂 Project Structure

QuranReader/
├── quran_reader.py
└── quran_data/
    ├── surahs.json
    ├── favorites.json
    ├── progress.json
    └── surah_*.json

The quran_data directory is created automatically when the application runs.

🎯 Project Goal

The goal of this project is to make reading and exploring the Holy Quran accessible through a simple, lightweight, bilingual command-line application.

📜 Disclaimer

English translations are interpretations of the meanings of the Quran. Quran text and translations are retrieved from an external API. Please verify the accuracy and source of religious texts.
